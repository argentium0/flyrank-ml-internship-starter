ML-08 Capstone Modeling Lane

Predicting Search Performance Decline Across 79M Daily Rows

How a leakage-free machine learning workflow outperformed manual SEO heuristics by 36 percentage points on unseen client domains.

1. Framing & Problem Definition

SEO teams frequently waste editorial resources updating high-volume pages that have zero probability of traffic recovery, while missing mid-volume pages actively decaying in search results. The goal of this project was to build a machine learning model to score and rank content refresh opportunities.

Dataset Context: We analyzed the pseudonymized FlyRank warehouse release (78.8M daily rows across 104 client domains), restricting feature development to a mid-panel month partition (month=2026-03) and reserving subsequent months for outcome verification.

2. Safe Data Contract & Leakage Audit

In search analytics modeling, feature leakage is the #1 reason why models fail in production. We conducted an explicit Leakage Trap Experiment to prove our data contract integrity:

The Leakage Trap: When future-window metrics (e.g. post-decision April impressions) were included, a Decision Tree classifier achieved an inflated, near-perfect AUC of 1.0000.
The Honest Fix: Removing post-decision features and strictly enforcing historical observation boundaries yielded an honest baseline AUC of 0.6437.
-- DuckDB Feature Extraction Query (Zero Forward-Looking Leakage) SELECT client_hash_id, content_hash_id, AVG(gsc_avg_position) as avg_position, -- knowable at decision moment (SUM(clicks_90d) / NULLIF(SUM(impressions_90d), 0)) * 100 as ctr, SUM(sessions_90d) as sessions, c.word_count FROM fact_daily_march_2026 JOIN dim_content c ON fact_daily_march_2026.content_hash_id = c.content_hash_id GROUP BY client_hash_id, content_hash_id, c.word_count;

3. Model vs Baseline Comparison

All models were trained on 80% of client domains (25 clients, 23,837 rows) and evaluated on a Grouped Client Holdout (7 unseen clients, 6,163 rows) to measure true domain generalizability.

Model / Method AUC-ROC Precision@50 Precision@100
Base Rate (Random Choice) 0.5110 0.5110 0.5110
Week 4 Rule Baseline N/A (Rule) 0.4200 0.4700
Logistic Regression (Winner) 0.6125 0.7800 0.7800
Random Forest Classifier 0.5965 0.6200 0.6200
HistGradientBoosting Classifier 0.5935 0.6600 0.7000

Key Result: Logistic Regression delivered the highest ranking precision on unseen clients (Precision@50 of 0.7800), beating the random base rate by +26.9 percentage points and outperforming the manual rule baseline by +36.0 percentage points.

4. Feature Importance & Diagnostic Interpretation

Permutation importance on holdout test clients revealed the primary physical drivers of content decline:

Feature Importance Mean Interpretation
log_impressions_90d 0.0372 Higher volume pages experience more noticeable impression drops.
avg_position 0.0188 Pages outside top-10 positions decay rapidly without updates.
log_clicks_90d 0.0154 Historical click volume signals active audience demand.
ctr 0.0102 Low CTR relative to position indicates snippet/intent mismatch.
